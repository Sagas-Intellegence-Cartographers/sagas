# Brand

The Sagas logo, colours and favicons, for every app that shows the project: the landing page, the
reading site and the contributing app. Use these files as they are rather than copying the
colours into your own code by hand, so a change happens in one place.

## The idea

An editor's palette: black ink, white paper, and a red pencil. The red dots under the name are
the same dotted underline the reading site uses for a phrase you can open, so the mark says what
Sagas does: every phrase leads to who said it.

## Files

| File | Use it for |
|---|---|
| `wordmark.svg` | The name, on a light background |
| `wordmark-on-ink.svg` | The name, on a dark background |
| `mark.svg` | A square mark, where the full name won't fit |
| `favicon.svg` | The browser tab icon, for browsers that take SVG |
| `favicon-32.png`, `favicon-16.png` | The browser tab icon, for the rest |
| `apple-touch-icon.png` | The icon a phone shows when someone saves the site to their home screen (180 by 180) |
| `favicon-512.png` | A large copy, for app manifests |

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#141414` | Text, and dark backgrounds |
| Paper | `#FAF8F3` | Page backgrounds |
| Red | `#B3001B` | Accents and links on Paper. It contrasts 6.75 to 1 with Paper, so it's fine for text |
| Red on ink | `#E0303F` | Accents on Ink. It contrasts 4.09 to 1 with Ink, so use it for marks and large text only |

Keep red for emphasis: links, the dotted underline, and the one thing on a screen that matters
most. A page that's mostly red loses the point of it.

## Type

The wordmark uses Georgia, a serif that ships with most computers. The SVGs name it as text, so
they render in whatever close serif a machine has. A version with the letters as outlines, which
looks the same everywhere, comes later. For the site's body text, pair a serif for headings with a
plain sans serif for everything else, and check the licence of any web font before adding it.
